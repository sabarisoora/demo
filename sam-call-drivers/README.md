# Sam Call Drivers website

Single-page static site for Sam Call Drivers. No build step: `index.html` plus the `assets/` folder.

- **Preview locally:** open `index.html` in a browser, or run `npx serve .` in this folder.
- **Host it:** drag this folder into Netlify Drop, or deploy it as its own Vercel / GitHub Pages / any static host project with this folder as the root.
- **Phone / WhatsApp number:** `+91 90929 16836` (search for `9092916836` in `index.html` to change it).
- **Booking form:** opens WhatsApp with the customer's details pre-filled. No server or database needed.
- **Photos:** optimised WebP copies of the supplied photos are in `assets/`. Replace a file with the same name to swap a photo.
